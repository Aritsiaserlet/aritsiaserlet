# 🗂️ สารบัญและโครงสร้างเว็บไซต์ (Site Table of Contents)

เอกสารนี้รวบรวมและอธิบายโครงสร้างของเว็บไซต์ทั้งหมด ว่าไฟล์แต่ละไฟล์มีไว้ทำไม หน้าต่าง ๆ ใช้สำหรับอะไรบ้าง เพื่อให้ง่ายต่อการพัฒนาและดูแลรักษาในอนาคต

---

## 🌐 1. หน้าเว็บหลัก (HTML Pages)

หน้าเว็บต่างๆ ที่ผู้ใช้สามารถเข้าถึงได้ แต่ละหน้าจะแยกตามวัตถุประสงค์การใช้งานอย่างชัดเจน:

*   **`index.html`**
    *   **หน้าที่:** หน้าแรกสุดของ Portfolio (Main Landing Page)
    *   **รายละเอียด:** ใช้สำหรับนำเสนอโปรไฟล์เบื้องต้น มี Loading Screen สไตล์ Pixel Art แสดงผลตอนโหลดเข้าเว็บ, มี Showcase ผลงานแบบ 3D Carousel และมีปุ่มลิงก์ไปยังหน้าเล่นเกมและหน้าผลงานแบบเต็ม
*   **`portfolio.html`**
    *   **หน้าที่:** หน้ารวมผลงานแบบละเอียด (Gallery)
    *   **รายละเอียด:** แสดงผลงานทั้งหมด สามารถจัดเรียง (Sort) และกรอง (Filter) ตามหมวดหมู่ได้
*   **`portfolio-ozonz.html`**
    *   **หน้าที่:** หน้า Portfolio เฉพาะกิจ (Ozonz Project)
    *   **รายละเอียด:** หน้าที่ออกแบบแยกมาเฉพาะสำหรับโปรเจกต์ Ozonz
*   **`lovertian.html`**
    *   **หน้าที่:** หน้าเว็บพิเศษ (Romantic/Gift Page)
    *   **รายละเอียด:** หน้าของขวัญสุดพิเศษที่มีลูกเล่นเปิดกล่องของขวัญ 3 กล่อง (รูปภาพ, เพลง, จดหมาย) พร้อมตัวนับเวลาความสัมพันธ์แบบ Real-time
*   **`game.html`**
    *   **หน้าที่:** หน้าเล่นมินิเกม
    *   **รายละเอียด:** มินิเกมสไตล์ Pixel Art ให้ผู้ใช้ได้เล่นบนเว็บ
*   **`admin.html`** / **`admin-ozonz-page.html`** / **`lovertian-admin.html`**
    *   **หน้าที่:** ระบบหลังบ้าน (Admin Panels)
    *   **รายละเอียด:** ใช้สำหรับอัปโหลด จัดการ และตั้งค่าข้อมูลของหน้าเว็บต่างๆ (เช่น เพิ่มรูปใน portfolio, เปลี่ยนเพลงหน้า lovertian) โดยต้องใช้ Token ในการเข้าถึง
*   **`404.html`**
    *   **หน้าที่:** หน้า Error
    *   **รายละเอียด:** แสดงผลเมื่อผู้ใช้เข้า URL ที่ไม่มีอยู่จริง
*   **`wind-vfx-demo.html`**
    *   **หน้าที่:** หน้าทดสอบระบบเอฟเฟกต์
    *   **รายละเอียด:** ใช้สำหรับเทสและโชว์ระบบลมและ Particle (Wind VFX)

## ⚙️ 2. ระบบโค้ดหลัก (JavaScript - โฟลเดอร์ `js/`)

ไฟล์สำหรับควบคุมการทำงาน (Logic) ของหน้าเว็บแต่ละส่วน:

### **กลุ่มจัดการระบบส่วนกลาง (Core Managers)**
*   **`authManager.js`**: จัดการระบบเข้าสู่ระบบ/สมัครสมาชิก (Authentication)
*   **`audioManager.js`**: ควบคุมเสียงเพลงพื้นหลัง (BGM) และเสียงเอฟเฟกต์ (SFX) ทั้งหมดในเว็บ
*   **`settingsManager.js`**: จัดการการตั้งค่าของผู้ใช้ เช่น ระดับเสียง และบันทึกลง Local Storage
*   **`toastManager.js`**: ระบบแจ้งเตือนแบบป๊อปอัป (Toast Notifications) มุมจอ
*   **`config.template.js`**: ไฟล์ตั้งค่าเริ่มต้น (Template) สำหรับเชื่อมต่อ API หรือ Firebase

### **กลุ่มหน้าหลักและ Portfolio**
*   **`index.js` / `index-module.js`**: ควบคุมหน้า `index.html` (อนิเมชัน, ระบบ Loading, การเลื่อนหน้าจอ)
*   **`portfolio.js`**: ระบบกรอง หมวดหมู่ และแสดงผลแกลลอรีในหน้า Portfolio
*   **`portfolio-skills.js`**: ควบคุมการแสดงผลหลอดพลังหรือทักษะ (Skills)
*   **`portfolio-timeline.js`**: ควบคุมการแสดงผลประวัติการทำงานแบบ Timeline
*   **`portfolio-ozonz.js` / `portfolio-ozonz-live.js`**: ควบคุมฟังก์ชันเฉพาะของหน้า Ozonz

### **กลุ่มเกมและ VFX**
*   **`game.js` / `game-module.js` / `game-lobby.js`**: ระบบหลักของมินิเกม การเข้าห้อง Lobby ระบบฟิสิกส์และการโต้ตอบในเกม
*   **`wind-vfx.js`**: โค้ดสร้างระบบ Particle สภาพอากาศ (ลม, ใบไม้ปลิว)

### **กลุ่มระบบหลังบ้าน**
*   **`admin.js`**: โค้ดสำหรับจัดการ Data และติดต่อกับฐานข้อมูลเมื่อแอดมินแก้ไขข้อมูลบนเว็บ

## 🎨 3. การออกแบบและเทคโนโลยีอื่นๆ (Styles & Configs)

*   **โฟลเดอร์ `css/`**: เก็บไฟล์ CSS หลักที่ควบคุมความสวยงามของเว็บ (สี, ฟอนต์ Pixel, การจัดวาง)
*   **`tailwind.config.js`**: ไฟล์ตั้งค่า Tailwind CSS (สำหรับจัดการ Utility Classes ของ CSS)
*   **โฟลเดอร์ `Design Project Feature UI/`**: โค้ดส่วนต่อขยาย (React/Next.js UI Components) ที่มีการแยกโครงสร้าง UI แบบสมัยใหม่ (shadcn/ui) เตรียมไว้สำหรับการพัฒนาฟีเจอร์ระดับสูงในอนาคต
*   **`firebase.json` / `firestore.rules` / `.firebaserc`**: ไฟล์ตั้งค่าสำหรับระบบ Firebase (ฐานข้อมูลและการโฮสต์เว็บไซต์)
*   **โฟลเดอร์ `md/`**: เก็บเอกสารต่างๆ ของโปรเจกต์ (รวมถึงเอกสารสรุปตัวนี้ด้วย)
